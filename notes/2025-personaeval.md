# PersonaEval：LLM 裁判能否认出角色

原文：[arXiv 2508.10014](https://arxiv.org/abs/2508.10014)；本地 PDF 首页标示 COLM 2025 会议版。精读依据为 23 页全文。

## 研究问题

若一个裁判连人类写的对话是谁说的都认不出，其「角色忠实」评分能否可信？作者将角色识别视为角色评审的必要条件，并做有正确答案的分类测试。

## 方法

- 每题提供已知说话人的第一轮、待辨说话人的第二轮及四个带资料的候选角色（专业受众轨道为五个）；候选顺序随机化（PDF pp. 4–5）。
- 三轨来自人类写作材料：文学 26,208 例、戏剧 1,658 例、按不同知识层级解释的专家视频 699 例，共 28,565。用相似人物资料构造难负例；先去掉少于 25 token 的回答，再保留 Qwen-max 对正确项信心低于 0.5 的题（pp. 4–6，Figure 2）。它刻意是**困难样本**，不是所有角色对话的自然分布。
- 测多种 LLM 的 top-1 分类准确率；另请 20 名人类参与者各做 50 道从 DeepSeek-R1 高信心答错集合抽出的题（pp. 6–8）。

## 实验与发现

- 全 benchmark 上，Gemini-2.5-pro 最高 top-1 为 68.8%，GPT-4o 为 40.9%；正确角色进入前二的比例分别为 92.6% 和 83.2%（pp. 6、17，Figure 3 与 Table 1）。
- 人类参与者在**专门抽出的 50 道题**上平均 90.8%（p. 8）。此数与模型在 28,565 道全量题上的 68.8% **不是同一测试集的配对比较**；作者认为抽样偏难，但不能当成严格的逐题差距估计。
- 文中案例指出只匹配表面措辞会误判人物意图与视角；强化推理的模型总体表现更好（pp. 7–8）。这是对裁判能力的诊断，未直接测角色生成质量。

## 局限

两轮分类仅是多轮角色评审的一个前提，认对人物也未必能判技能上限、行动后果与情绪轨迹。Qwen-max 低置信度过滤可能使结果偏向某类模型难题；候选资料本身可提供不对称线索。人类样本量仅 50 道且选题条件不同，跨语言/作品的外推需另验。

## 对本项目的启发

**研究设想：** 让 LLM 裁判先做配对的「角色是谁」「当前时点知道什么」「这个动作是否在能力范围」三项校准；与盲评的人类意见逐项比较。匿名角色测试仍提供等量证据卡，以减弱知名角色名称和口头禅捷径。裁判与生成器分开，所有自动评分保留人工复核样本。
