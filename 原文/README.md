# 本机论文原文

这里存放已核验的 **86 份论文 PDF**，按主要研究线索和首次公开年份排列，例如 `原文/ability-boundaries/2025/`。每篇只存一份；跨主题的论文从[分主题索引](../literature/by-theme/)交叉查找。文件名以稳定论文 ID 开头，便于和[书目目录](../catalog/papers.jsonl)对应。

PDF 只保留在这台电脑，不提交到 GitHub。因此从 GitHub 浏览此目录时只会看到本说明文件；本机文件管理器中可直接打开下面的子文件夹。下载状态和 SHA-256 见[核验报告](../research/validation-report.md)。

当前唯一未取得全文的是 Act-LLM，目录记为 `unavailable`。此处没有原作书籍、剧本或台词全文。
