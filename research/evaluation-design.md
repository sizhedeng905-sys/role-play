# 可复现评测草案（研究设想，尚未执行）

## 1. 证据与样本单位

每个目标角色只选定一个**原作时间截面**。研究者手工建立最小证据卡：`scene_id`、作品与章节/集数、角色可见信息、关系、可观察动作、情绪线索、允许的简短引文或意译、时间、证据性质（明示/推断/未知）及标注者。原作全文与台词语料保持本地。对同一事实记录「作品世界中为真」「此时角色可知」两个布尔值，避免把读者知识误当角色知识。[TimeChara](https://aclanthology.org/2024.findings-acl.197/) 提供时间点知识测试的直接参照。

## 2. 题型与期望行为

| 题型 | 构造方法 | 主要观察量 |
| --- | --- | --- |
| 原作场景复现 | 从有明确行为后果的场景抽样，隐藏角色原句；给出截断在当时的前情。 | 选择动作、动机、知识及关系是否与证据卡相符；台词相似性只作次要指标。 |
| 未见新情境 | 改变地点、互动对象或目标，但保留角色价值冲突与技能难度；人工检查没有训练场景直接答案。 | 合理迁移、稳定习惯、推断证据与不确定性。 |
| 应当不知道 | 未来剧情、私有信息、未见事件与时代错位问题各自成组；包括间接诱导。 | 是否泄漏、是否承认未知、是否合理追问；参考 [TimeChara](https://aclanthology.org/2024.findings-acl.197/) 和 [Tell Me What You Don’t Know](https://aclanthology.org/2025.findings-acl.311/)。 |
| 会尝试但能力有限 | 原作已显示角色想做却做不好的技能、专业任务或社交任务；写明目标、可尝试路径和失败条件。 | 是否尝试、成功上限、失败后的调整/求助；知识边界与专业技能分列，参照 [DMT-RoleBench](https://ojs.aaai.org/index.php/AAAI/article/view/34768) 的分项思路。 |
| 多轮情绪与关系 | 连续 6–12 回合逐步改变他人态度、环境与可见事实；在中途加入一次误解或挫折。 | 情绪变化是否有因果、是否记住承诺与关系转折；参考 [EmoCharacter](https://aclanthology.org/2025.naacl-long.316/) 与 [PsyMem](https://aclanthology.org/2026.tacl-1.24/)。 |
| 行动结果 | 为每回合定义有限动作、前置条件及可观测世界状态。 | 台词承诺、动作执行、世界结果是否一致；参考 [STSS](https://aclanthology.org/2024.findings-acl.526/) 和 [RolePlot](https://aclanthology.org/2025.acl-long.603/)。 |
| 匿名角色 | 去掉姓名和高辨识度专名，保留等价的经历与动机卡。 | 评审能否从行动模式判断一致性，排除只认出角色名的捷径；参考 [匿名评测论文](https://aclanthology.org/2026.sigdial-1.15/)。 |

**关键区分：**「角色不知道答案」与「角色知道原理但做不到」各设正例、反例。社交测试再单列「想安慰却表达生硬」「根本无意安慰」「熟练安慰」等条件；只在原作支持时使用相应标签，不能预设所有人都笨拙。

## 3. 标注和评分

- 每题由两名独立标注者先阅读证据卡，再写**可接受行为集合**及不可接受边界，而非单一标准台词。意见不同时由第三人裁决；记录分歧、证据不足与「无唯一合理答案」。
- 将**知识边界**、**技能/社交能力边界**、**动机价值**、**动作与结果**、**情绪关系轨迹**分别以 0–2 分标注；同时给出证据类型及置信度。不得用五项简单求和掩盖任何一项的越界。
- 角色失败可以得高忠实性分，只要失败形式和尝试/求助符合证据；高任务成功率不是目标函数。[STSS](https://aclanthology.org/2024.findings-acl.526/) 的行动指标适合核对执行层，但角色忠实度仍需另评。
- 人评以匿名、随机顺序比较不同系统的轨迹；报告每维均值、分歧率与带区间估计。LLM 裁判只作辅助，抽样审计其与人评的系统性偏差；[CPO / CharacterArena](https://aclanthology.org/2025.findings-emnlp.18/) 的轨迹比较可作为一种实验对照。

## 4. 切分、对照与复现

按作品章节/剧集与情节弧切分证据、开发题和最终盲测题；同一对话改写版本只进一个分区。记录模型版本、提示词、检索库快照、随机种子、温度、场景初始状态和可用工具。对每种方法重复运行，报告成功率与失败类型，而非只展示精选案例。

至少比较：(a) 角色简介提示词；(b) 时点检索；(c) 时点检索加条件行为规则；(d) 如未来获准训练，再比较角色微调及偏好优化。分别消融知识门控、技能规则、关系记忆与动作后果。当前阶段只建立文献库，不训练模型，也不构造受版权保护的原作语料。

## 5. 预注册的失败判据

逐项报告未来剧情泄漏、技能过度成功、应尝试时无条件拒绝、应求助时强行完成、情绪突变、关系遗忘、口头承诺但行动相反、匿名场景退化。每个错误附简短题目 ID 与证据卡 ID；没有足够原作证据的案例标为「无法判定」，不强行计错。
